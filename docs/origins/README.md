# Remembrances of the Mythical Elden Days of TJAI

These documents record TJAI's founding vision, early design decisions,
superseded operating references, unimplemented proposals, and retired backlog.
They are preserved for history and context. They do not describe the current
system authoritatively.

Current TJAI documentation begins at [`../../../tjai/README.md`](../../../tjai/README.md).

## Documents

- `implementation_notes.md` - original purpose, architecture, and command notes
- `NOTES.md` - early notation and interaction design decisions
- `PLUGINS.md` - proposed machine-specific plugin architecture
- `OPERATORS.md` - superseded 2025 CLI operator reference
- `next_steps.md` - retired file-based plans and idea backlog, replaced by TJAI
  entries and todos
